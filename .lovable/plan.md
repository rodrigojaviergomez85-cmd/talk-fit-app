# Conectar proyecto con GitHub (Git sync)

## Objetivo
Vincular el proyecto FLUENCY REPS a un repositorio de GitHub para que los cambios de código se sincronicen automáticamente entre Lovable y GitHub.

## Pasos a realizar

1. **Abrir el menú GitHub en el editor de Lovable**
   - En la entrada del chat, hacer clic en el menú **Plus (+)**.
   - Seleccionar **GitHub → Connect project**.

2. **Autorizar la app de Lovable en GitHub**
   - Seguir el flujo OAuth para autorizar la Lovable GitHub App.
   - Elegir la cuenta personal u organización de GitHub donde vivirá el repo.

3. **Crear el repositorio**
   - En la tarjeta de Lovable, hacer clic en **Create Repository**.
   - Esto genera un repo nuevo con el código actual del proyecto.

4. **Confirmar sincronización bidireccional**
   - Una vez conectado, los cambios hechos en Lovable se empujan a GitHub automáticamente.
   - Los cambios hechos en GitHub (incluyendo push local) se sincronizan de vuelta a Lovable.

## Notas
- No se requieren cambios de código en el proyecto para esta conexión.
- Si más adelante se quiere desconectar o cambiar de repositorio, se hace desde el mismo menú GitHub en Lovable.
